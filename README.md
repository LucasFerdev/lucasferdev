# 👋 Olá, sou Lucas Fernando.

### Desenvolvedor Android | Kotlin • Jetpack Compose • MVVM | Java • Spring Boot • APIs REST

Sou desenvolvedor de software com foco em **Android nativo**, utilizando Kotlin, Jetpack Compose, MVVM e integração com APIs REST.

Atualmente curso **Análise e Desenvolvimento de Sistemas na FIAP** e atuo como freelancer no desenvolvimento de soluções mobile e web.

Também desenvolvo aplicações back-end com Java e Spring Boot, criando APIs REST, autenticação, regras de negócio e persistência de dados. Minha experiência full stack me permite compreender o desenvolvimento de um sistema de ponta a ponta, da interface ao banco de dados.

Busco oportunidades como **Desenvolvedor Android Júnior**, **Mobile Developer** ou **Desenvolvedor Back-end Java Júnior**.

## 📱 Desenvolvimento Mobile

- Android nativo com Kotlin e Jetpack Compose
- Arquiteturas MVVM e Clean Architecture
- Navigation, ViewModel, StateFlow e Coroutines
- Persistência local com Room
- Integração com APIs REST usando Retrofit
- Firebase Authentication e Firestore
- Desenvolvimento multiplataforma com Flutter e Dart

## ⚙️ Back-end e Web

- APIs REST com Java e Spring Boot
- Persistência com JPA e Hibernate
- Autenticação com Spring Security e JWT
- Testes com JUnit e Mockito
- Bancos de dados SQL e NoSQL
- Interfaces web com React, JavaScript e TypeScript
- Versionamento com Git e ambientes com Docker
